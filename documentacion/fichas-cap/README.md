# Formatos oficiales de fichas del CAP

Escaneados de los formatos que el CAP usa hoy en papel para registrar la información de pacientes.

## Para qué sirven

De aquí sale la plantilla de impresión del **RF-07**. Si el PDF que genera el sistema no se parece
al formato que el personal ya conoce, el módulo de impresión no se usa y el sistema pierde su razón
de ser.

## Dato a confirmar al recibirlos

¿Se imprimen **en hoja en blanco** o **sobre papel preimpreso** donde el sistema solo llena los
espacios? El segundo caso exige posicionamiento milimétrico y calibración contra la impresora real
del CAP. Cambia la plantilla, no la arquitectura.

## El contenido de esta carpeta NO se versiona

Los escaneados pueden contener datos reales de pacientes. El `.gitignore` de la raíz excluye todo lo
que se coloque aquí, salvo este README.

Los archivos se comparten por el medio que el CAP autorice, nunca subiéndolos al repositorio.
