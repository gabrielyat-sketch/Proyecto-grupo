# Documentación del proyecto

Documentos institucionales y de gestión. **El código no vive aquí.**

## Qué va en cada carpeta

| Carpeta | Contenido |
|---|---|
| `plan/` | `Plan de Desarrollo v2.docx` y sus versiones posteriores |
| `requerimientos/` | SRS, historias de usuario, backlog priorizado (MoSCoW) |
| `fichas-cap/` | **Formatos oficiales escaneados** que hoy usa el CAP en papel |
| `legal/` | Autorización institucional, consentimiento informado, titularidad de datos |
| `actas/` | Actas de reunión con el CAP y retrospectivas de sprint |
| `capacitacion/` | Material de capacitación por rol y manual de usuario |

## Por qué `fichas-cap/` importa más de lo que parece

De esos escaneados sale la plantilla de impresión del RF-07. Si el PDF que genera el sistema no se
parece al formato que el personal ya conoce, el módulo de impresión no se usa y el sistema pierde su
razón de ser. Conseguirlos es tarea de la **Etapa 0**.

Al recibirlos hay que confirmar un dato: si se imprimen **en hoja en blanco** o **sobre papel
preimpreso**. Cambia la plantilla, no la arquitectura.
